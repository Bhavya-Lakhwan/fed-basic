## 🚀 How to Run Locally

1. Simply double-click [`index.html`](index.html) to view it in any web browser.
2. Or use Python to start a local development server:
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000`.

---

## ✏️ How to Customize Your Info

- **Profile Picture:** Replace the `.avatar-placeholder` initials in `index.html` with an `<img>` tag pointing to your photo:
  ```html
  <img src="your-photo.jpg" alt="Bhavya Lakhwan" class="avatar-img">
  ```
- **Social Links:** Update your LinkedIn, GitHub, and email address in the `#contact` section of `index.html`.
- **Bio & Summary:** Modify the paragraphs in the `#about` section to reflect any updates or milestones!

---

## 🌐 How to Host on GitHub Pages (Free)

1. Create a new GitHub repository named `portfolio` (or `<your-username>.github.io`).
2. Push `index.html`, `styles.css`, and `script.js` to the repository.
3. In GitHub, go to **Settings** $\rightarrow$ **Pages** $\rightarrow$ select **Branch: main** $\rightarrow$ **Save**.
4. Your website will be live at `https://<your-username>.github.io/portfolio/`!
